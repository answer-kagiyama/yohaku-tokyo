# ADR 0008: 空間集計は GeoPandas + 平面直角座標系 IX 系、網羅性は逆ジオコーダで判定する

- Status: Accepted
- Date: 2026-09-28

## Context
駅から 500m の施設判定を、緯度経度の単純差分ではなく正しい距離で行う必要がある（指示書 §12）。
また、施設が 0 件に見えても「その区のデータがない」だけの可能性があり、欠損と 0 を区別しなければならない（指示書 §26）。

## Decision
- GeoPandas / Shapely / pyproj を導入し、EPSG:6677（JGD2011 / 平面直角座標系 IX 系, m）で `dwithin` 判定する。
- 駅の 500m 圏に掛かる区市町村を、国土地理院 逆ジオコーダで 25 点サンプリングして求める（ADR 0007 と同じ提供元）。
- 圏内の区市町村のデータが揃っていない駅は、施設数を null（欠損）とする。

## Alternatives
- 行政区域ポリゴン（国土数値情報 N03）との交差: 正確だが別ライセンス・大容量データの管理が増える。駅数が増えて
  サンプリングの限界が問題になった段階で再検討する。
- haversine 距離のみ: 依存は減るが、今後の面積・ポリゴン処理（公園面積、駅勢圏など）で結局 GIS が必要になる。

## Dependencies
| package | 理由 |
| --- | --- |
| geopandas | 空間結合（sjoin dwithin）|
| shapely | ジオメトリ |
| pyproj | 投影変換・測地線計算（サンプル点生成）|
