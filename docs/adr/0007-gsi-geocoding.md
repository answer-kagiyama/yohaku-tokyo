# ADR 0007: 住所のみの施設は国土地理院 住所検索 API でジオコーディングする

- Status: Accepted
- Date: 2026-09-27

## Context
Step 4 の探索で、区市町村の「都市公園・都立公園一覧」の多く（24 件）が `緯度`/`経度` 列を持つが値が空で、住所のみだった。
MVP 対象の千代田区（秋葉原・神田）も該当し、座標なしでは 2 駅の公園数を算出できない。

## Options
| 案 | 評価 |
| --- | --- |
| 国土地理院 住所検索 API | 無料・API キー不要・日本の住所に強い。公式 SLA はない |
| 見送る（欠損扱い）| 正直だが 5 駅中 2 駅の park が欠損 |
| 商用ジオコーダ（Google 等）| 高精度だがキーと費用が必要。MVP 方針（ローカル再現性）に合わない |

## Decision
国土地理院 住所検索 API（`msearch.gsi.go.jp/address-search/AddressSearch`）を使う（ユーザー判断 2026-09-27）。

- `Geocoder` を抽象化し、GSI 実装を差し替え可能にする。
- 結果はキャッシュし、`coordSource: "geocode"`・一致した住所・精度（exact / partial）を施設ごとに記録する（provenance）。
- **API は存在しない住所にも区市町村の代表点を返す**ため、区市町村レベルの結果は採用しない。
- リクエスト間隔を空け、少量ずつ呼ぶ。

## Consequences
- 住所のみのデータセットも accepted にできる（spec 0002 改訂、spec 0003）。
- 丁目レベルの partial 一致は 100〜200m 程度ずれ得る。500m 判定への影響は Step 6 の境界付近で注意する。
- API の停止・仕様変更時はキャッシュで再現でき、新規分は `unlocated`（欠損）として扱われる。
