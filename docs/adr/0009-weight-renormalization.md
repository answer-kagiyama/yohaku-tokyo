# ADR 0009: 欠損・比較不能な特徴量の重みは残りへ再配分し、定義上の重みは変えない

- Status: Accepted
- Date: 2026-09-28

## Context
観光（重み 25%）は千代田区にデータがなく、対象 5 駅では比較不能になった（spec 0005）。
重みを恒久的に配り直すか、定義上の重みを保ったまま計算時に再配分するかを決める必要があった。

## Decision
定義上の重み（`docs/scoring.md` §4）は変えない（ユーザー判断 2026-09-28）。
計算時に、値のない特徴量の重みを残りの特徴量へ比例配分する（実効重み）。
実効重みと coverage を出力し、UI で定義上の重みと並べて表示する。

## Consequences
- 観光データのある区の駅が増えれば、設定変更なしで観光がスコアに入る。
- 駅によって実効重みが異なりうる（coverage が違う場合）。その差は UI で見えるようにする。
- coverage < 0.5 の駅はスコアを出さない（既存ルール）。
