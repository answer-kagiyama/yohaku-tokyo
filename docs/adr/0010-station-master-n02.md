# ADR 0010: 駅マスタは国土数値情報「鉄道データ」（N02）から作る

- Status: Accepted
- Date: 2026-09-28

## Context
対象駅を数十駅（山手線 30 駅）へ広げるには、駅の座標と路線が必要。
東京都オープンデータカタログには全駅の座標付き一覧がない（都営地下鉄の駅基本情報のみ）。

## Decision
国土交通省「国土数値情報 鉄道データ（N02）」の最新年版を使う（ユーザー判断 2026-09-28）。
- 2020 年以降のデータは CC BY 4.0。出典表示:「国土数値情報（鉄道データ）」（国土交通省）を加工して作成。
- ダウンロード URL は `pipeline/config/stations.yaml` に 1 件だけ記載する（自治体ごとの URL 収集ではない）。
- 駅名は人が定義し（概念）、座標・路線は N02 から取る。

## Consequences
- 東京都カタログ以外の出典が 1 つ増える。UI の出典・データ台帳に明記する。
- 数百駅（Phase 4）も同じ仕組みで扱える（駅名リストを路線・区単位で生成すればよい）。
